# Green API Chat Prototype

Простой React-прототип чата в стиле MAX для тестирования отправки и получения текстовых сообщений через Green API.

## Что реализовано

- ввод `idInstance` и `apiTokenInstance`
- ввод номера получателя
- создание нового чата
- отправка текстовых сообщений через Green API
- polling входящих сообщений
- минимальный интерфейс чата, похожий на MAX

## Требования

- Node.js 18+
- npm
- активный аккаунт Green API
- валидный `idInstance` и `apiTokenInstance`

## Установка

```bash
cd chat-app
npm install
```

## Запуск в режиме разработки

```bash
npm run dev -- --host 0.0.0.0
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173/
```

## Сборка проекта

```bash
npm run build
```

Готовый сборочный результат будет в папке `dist/`.

## Как использовать

1. Откройте приложение в браузере.
2. Введите `idInstance` и `apiTokenInstance` из личного кабинета Green API.
3. Введите номер получателя.
4. Нажмите `Создать чат`.
5. Введите текст сообщения и нажмите `Отправить`.
6. Если получатель отвечает, сообщение появится в интерфейсе через polling.

## Важно

Для корректной проверки реальной доставки необходим:

- активный Green API instance;
- корректный номер получателя в формате, поддерживаемом Green API;
- реальный получатель, который может ответить на сообщение.
